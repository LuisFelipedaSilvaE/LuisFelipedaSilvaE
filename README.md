I'm **Luis Felipe da Silva Euzebio**, an **Analysis and Systems Development** student from Brazil who enjoys understanding how applications work from the interface to the database.

- 🔭 Currently building **Flux**, a real-time chat application with Angular, Spring Boot and WebSockets
- 🎓 Developing **Ongaku** as my graduation project — a platform focused on organic music discovery and social interaction

- 🌱 Deepening my knowledge of real-time applications, software architecture, security and accessible interfaces
- 🐧 Daily Linux user who enjoys solving problems through code, documentation and a terminal
- 💬 Ask me about **Java, Spring Boot, Angular, TypeScript, JPA, REST APIs and WebSockets**
